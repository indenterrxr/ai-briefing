AI 브리핑 — 2026년 11월 04일

11월 4일 브리핑의 키워드는 맥락을 오래 유지하는 에이전트와, 그 주변의 운영·보안 경계다. Anthropic은 장기 대화에서 전송량을 줄이는 Message Threads를 베타로 공개했고, Google은 Gemini 2.5 계열의 자동 전환 일정을 알렸다. 한편 공격자들은 인기 AI 제품명을 미끼로 악성 설치 파일을 유포하고 있다.

오늘의 핵심

  • Claude Message Threads 베타는 장기 에이전트 대화에서 새 메시지만 보내도록 해 첫 응답까지의 지연을 줄인다. 단, 앱이 전체 대화의 원본을 직접 보관해야 한다.
  • Gemini 2.5 Pro·Flash는 12월 1일부터 각각 Gemini 3.8 Flash와 3.5 Flash-Lite로 자동 라우팅된다. 단순 모델명 교체가 아닌 API 호환성 점검이 필요하다.
  • Yoba 악성코드 캠페인은 가짜 GitHub 프로젝트로 ChatGPT·Claude 데스크톱 앱을 사칭하고, 정상 서명 바이너리를 DLL 사이드로딩에 악용했다.

1. Claude Message Threads 베타: 긴 에이전트 대화의 재전송을 줄인다

매번 전체 기록을 보내지 않고, 새 턴만 이어 붙이기

Anthropic의 Claude Platform 문서에 따르면 Message Threads는 Messages API의 베타 기능이다. 첫 요청에서 대화 전체와 시스템 프롬프트·도구를 보내고, 이후 요청에서는 새 메시지와 직전 응답 ID만 보내 서버가 이어서 처리한다. 긴 에이전트 루프에서 요청 직렬화와 업로드 부담을 줄여, 첫 토큰이 나오는 시간을 단축하는 방식이다.

  • 사용하려면 각 요청에 message-threads-2026-08-12 베타 헤더를 넣어야 한다.
  • 계속 요청에서는 system과 tools를 보내면 안 되며, 모델·도구 선택·thinking 등 고정 필드는 생성 요청과 일치해야 한다.
  • 스레드는 마지막 요청 후 5분에 만료되고, 이어가기 요청은 404가 될 수 있다. API가 1시간 이내에 삭제하므로 앱은 전체 대화를 자체 보관하고 재생성 경로를 구현해야 한다.
Message Threads는 토큰 과금을 없애는 기능이 아니라, 긴 대화의 전송·대기 병목을 줄이는 기능이다. 가격과 레이트 리밋은 바뀌지 않는다.

도입 전에는 장애 복구를 먼저 설계하는 편이 좋다. 스레드가 만료되었을 때 전체 문맥을 새 create 요청으로 되보내는 처리, 재시도 중 중복 메시지를 막는 로직, 그리고 자체 대화 저장소를 갖춰야 한다. 또한 이 기능은 ZDR(Zero Data Retention) 및 HIPAA 대상이 아니다.

2. Gemini 2.5 Pro·Flash, 12월 1일 자동 전환 예고

모델 ID가 살아 있어도 동작·요금이 달라질 수 있다

Google의 Gemini API 릴리스 노트는 11월 2일 Gemini 2.5 Pro와 Gemini 2.5 Flash의 지원 중단 일정을 공지했다. 두 모델은 이미 AI Studio에서 선택할 수 없으며, 12월 1일부터 기존 API 요청이 대체 모델로 자동 라우팅된다.

  • gemini-2.5-pro 요청은 Gemini 3.8 Flash로 전환되고, 해당 모델의 요금으로 청구된다.
  • gemini-2.5-flash 요청은 Gemini 3.5 Flash-Lite로 전환되고, 이 역시 대체 모델의 요금이 적용된다.
  • Google은 모델 문자열을 직접 바꾸고 마이그레이션 가이드를 검토하라고 권고한다. 함수 호출과 thought_signature 검증, thinking_level 전환, 샘플링 파라미터·미리 채운 모델 턴 제거 등 호환성 변경이 포함된다.

자동 라우팅은 서비스 중단을 피하게 해주지만 결과 품질·도구 호출 형식·비용이 이전과 같다는 보장은 아니다. 프로덕션 팀은 12월 전에 회귀 테스트를 돌리고, 모델명을 명시적으로 바꾸며, 에러율·지연·토큰 비용을 기존 기준선과 비교해야 한다.

3. 가짜 ChatGPT·Claude 앱으로 정상 서명 바이너리까지 악용한 Yoba 캠페인

GitHub 검색 결과와 AI 제품명을 신뢰하게 만드는 공급망형 미끼

Check Point Research의 Yoba 분석 보고서는 공격자들이 GPT-5.6 Sol, GPT-6 Astra, Claude Opus 같은 이름의 가짜 데스크톱 앱을 내세운 GitHub 프로젝트를 사용했다고 설명한다. 검색 최적화(SEO poisoning)로 외부 검색에서 상위에 노출될 수 있도록 만들고, GitHub Release ZIP을 내려받게 유도하는 방식이다.

  • 악성 구성요소는 OpenAI·Anthropic의 정상 서명 실행 파일 옆에 배치돼 DLL 사이드로딩으로 로드될 수 있었다.
  • 캠페인은 전용 C2 대신 Telegram, Tor, Catbox, DNS over HTTPS 등을 조합해 추적을 어렵게 하려 했다.
  • 보고서는 가짜 별·포크를 통한 GitHub 내부 검색 조작 증거는 없었지만, 외부 검색에서 상위에 나타나는 SEO 오염 정황을 지적한다.
서명된 실행 파일이 포함됐다는 사실은 다운로드의 정당성을 보장하지 않는다. 설치 패키지 전체의 출처와 배포 경로를 확인해야 한다.

사용자는 제품명 검색 결과나 제3자 GitHub 저장소 대신 공식 제품 페이지에서만 앱을 내려받아야 한다. 조직은 애플리케이션 허용 목록, 다운로드 출처 검증, 엔드포인트 탐지 규칙을 함께 운영하고, 새 모델 출시를 미끼로 한 설치 요청을 피싱 시나리오에 포함할 필요가 있다.
