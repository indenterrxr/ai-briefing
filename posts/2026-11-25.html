1. Claude Ship: AI가 PR을 검토하고 승인까지

Anthropic은 11월 23일 Claude Ship을 발표했습니다. 기존에 정식 제공 중인 Code Review와 베타인 PR Steward, Claude Approvals를 결합해 GitHub 풀 리퀘스트의 검토·수정·승인 판단을 지원합니다. PR Steward는 실패한 CI, 병합 충돌, 리뷰 의견을 처리하지만 스스로 승인하거나 병합하도록 설계되지는 않았습니다.

  • Claude Approvals는 저장소의 정책 파일을 읽고, 팀이 허용한 변경은 승인하거나 특정 상황에서 사람의 승인을 요구합니다. Anthropic은 우선 관찰 전용 모드로 시작할 것을 권합니다.
  • Claude Code의 /ship 명령은 변경사항을 푸시하고 PR을 열어 검토와 피드백 처리를 돕습니다. 병합 가능 여부는 사용자의 권한과 브랜치 규칙에 따릅니다.
  • Ship은 GitHub 저장소를 사용하는 Team·Enterprise 요금제에서 제공됩니다. 사용량은 토큰 기반으로 과금되며, 무보존(ZDR)·HIPAA 설정·고객 관리 암호화 키를 쓰는 조직에는 제공되지 않습니다.

코드 검토도 오류나 취약점을 놓칠 수 있습니다. 민감한 변경의 사람 승인과 브랜치 보호를 정책으로 유지하고, 자동 수정이 실제 테스트를 통과했는지 확인하는 것이 중요합니다.

2. Claude 아티팩트를 독립 데스크톱 앱으로 설치

Anthropic은 11월 24일 Claude에서 만든 아티팩트를 Mac·Windows 앱으로 설치하는 기능을 모든 요금제에 베타로 순차 배포한다고 밝혔습니다. 설치된 앱은 자체 아이콘과 창을 갖고, Claude와 연결된 서비스를 사용할 수 있으며, 원본 아티팩트가 수정되면 자동 업데이트됩니다. Claude 요청은 사용자의 요금제 사용 한도에 반영됩니다.

  • 기본 권한은 브라우저에서 가능한 수준이며, 알림·전역 단축키 같은 기능은 별도로 권한을 요청합니다.
  • 전체 컴퓨터 접근을 허용하면 프로그램 실행과 파일 읽기·변경·삭제가 가능해집니다. 해당 버전에만 권한이 적용돼 업데이트 후에는 다시 요청합니다. 다만 다른 웹사이트에서 가져온 부분은 재승인 없이 달라질 수 있습니다.
  • 전체 접근은 자신이 만든 앱 또는 Team·Enterprise에서 같은 조직 구성원이 만든 앱에만 허용할 수 있습니다. 온라인 상태와 Claude 로그인이 필요하며 Docs·Slides·Sheets 등 일부 아티팩트는 설치할 수 없습니다.

작은 업무 도구를 별도 패키징 없이 실행하기 쉬워졌지만, 설치 전에 앱이 요구하는 접근 범위와 출처를 살펴봐야 합니다.

3. Gemini 에이전트, 양자 알고리즘 비용을 줄이는 해법 탐색

Google DeepMind와 Google Quantum AI는 11월 23일 Gemini 4 에이전트 팀과 Lean 정형 검증을 사용해 양자 알고리즘 회로를 개선한 연구를 발표했습니다. 독립적인 에이전트 팀이 제안한 아이디어를 Lean으로 검증하고, 공유 노트와 주기적인 토론을 통해 개선안을 비교하는 방식입니다.

  • 관성 핵융합 시뮬레이션의 특정 계산에서는 큐비트와 연산을 결합한 비용 지표가 기존 대비 11.8배 줄고, 오류 보정 큐비트 요구량은 5,650개에서 4,338개로 줄었다고 연구진은 보고했습니다.
  • 빛에 반응하는 한 분자의 시뮬레이션은 8배, 약물 대사에 중요한 효소 Cytochrome P450의 사례는 2.5배 비용 개선을 보고했습니다.
  • 연구진은 Lean 라이브러리와 문제 명세, 검증된 해법을 공개했습니다.

이는 특정 알고리즘과 비교 기준에서의 이론적 자원 추정입니다. 연구진은 이 회로를 현재의 작은 양자 프로세서에서 실행하기 어렵고, 개선 후에도 초기 오류 보정 양자컴퓨터의 자원은 부족할 가능성이 크다고 설명합니다.

4. Codex와 Astra가 찾은 외계행성 후보

OpenAI는 11월 24일 두 아마추어 천문가가 공개 망원경 자료를 AI로 분석한 사례를 소개했습니다. OpenAI 엔지니어 Kevin Bond는 Codex로 케플러 망원경의 약 10만 개 별 관측치를 검색했고, 별빛이 주기적으로 어두워지는 두 유망 신호를 찾아냈습니다. SETI 연구소 천문학자의 독립 검색에서도 같은 두 신호가 나왔습니다.

별도로 Ethan Byrd는 Astra를 활용해 약 1,900만 개 별의 관측 자료를 분석했고, 첫 탐색에서 후보 49개를 얻어 그중 하나를 TESS 연구진에게 추가 분석용으로 전달했습니다. 이들은 아직 행성 발견 확정이 아닙니다. 다른 천체나 관측 장비의 영향도 비슷한 신호를 낼 수 있어 추가 관측과 검증이 필요하며, OpenAI는 확인에 수개월 또는 수년이 걸릴 수 있다고 설명합니다.

주목받은 안전성 논쟁

Axios는 11월 24일 내부 논의에 정통한 20여 명 이상의 소식통을 인용해, OpenAI와 Anthropic의 미공개 모델에 대해 일부 직원들이 안전하게 공개할 수 있는지 우려한다고 보도했습니다. 같은 기사를 공유한 Reddit 게시물에는 확인 시점에 152개의 추천이 표시됐고 회의적인 반응도 있었습니다. 이는 익명 소식통에 근거한 보도이며, 비공개 모델의 구체적 능력이나 우려의 타당성을 독립적으로 확인한 결과는 아닙니다.
