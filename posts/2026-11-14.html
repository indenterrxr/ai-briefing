AI 브리핑 — 2026년 11월 14일

한눈에 보기

오늘의 공통 키워드는 생성형 AI를 판단·운영 계층으로 옮기는 변화다. Google은 대량의 제한된 선택을 빠르게 점수화하는 전용 API를 내놓았고, OpenAI는 코딩 에이전트용 모델과 조직 통제를 함께 확장했다. Vercel의 운영 데이터도 실제 제품에서 ‘답변 생성’보다 ‘분류·라우팅·선택’ 용도가 급격히 늘고 있음을 보여준다.

모델의 능력 경쟁은 계속되지만, 기업 현장에서는 무엇을 생성할지보다 어떤 작업을 어떤 모델에 맡길지를 저지연·저비용으로 결정하는 계층이 빠르게 중요해지고 있다.

1. Google, Gemini Decisions API와 전용 판단 모델 공개

생성 대신 ‘선택’에 최적화

Google DeepMind는 11월 11일 Gemini Decisions API와 Gemini Decision 1을 공개했다. 정답 문장을 토큰 단위로 생성하기보다 후보 선택지를 한 번에 점수화해, 도구 선택·정책 검사·모델 라우팅·문맥 품질 평가처럼 결과가 정해진 업무를 겨냥한다.

  • 텍스트·이미지·오디오·동영상·PDF를 하나의 입력으로 처리하고, 최대 1,000개의 예/아니오·선택형·루브릭 질문을 함께 평가한다.
  • Google 발표 기준 종단 간 지연은 150~250ms, 입력 가격은 백만 토큰당 0.10달러이며 출력 토큰 과금은 없다.
  • 응답에는 선택 확률과 신뢰도 점수가 포함돼, 다음 단계를 자동화하되 임계값 이하 사례를 사람에게 넘기는 설계를 할 수 있다.

Google은 벤치마크에서 성능과 보정(calibration)이 앞선다고 밝혔지만, 해당 수치는 회사 측 평가다. 실제 도입 전에는 업무별 오류 비용과 불확실성 구간을 별도로 검증해야 한다.

2. OpenAI API, Codex 모델·권한 제어·24시간 캐시 동시 확장

에이전트 코딩과 조직 운영을 함께 겨냥

OpenAI는 11월 13일자 API 변경 기록에서 gpt-5.1-codex와 gpt-5.1-codex-mini를 Responses API에 추가했다. 전자는 Codex 같은 환경의 에이전트형 코딩 작업에 맞춘 GPT-5.1 변형이다.

  • 향상된 RBAC: API와 대시보드 모두에서 조직·프로젝트별로 누가 어떤 작업을 할 수 있는지 역할 기반으로 관리한다.
  • 확장 프롬프트 캐시: 반복되는 긴 접두 문맥을 최대 24시간 유지하도록 지원한다.
  • 활용 포인트: 공통 저장소·정책 문서·대형 코드베이스를 자주 다시 보내는 에이전트 워크플로에서 캐시 적중 여부를 측정하며 비용과 응답 시간을 관리할 수 있다.

특히 권한 제어와 캐시는 단순 모델 교체보다 운영팀에 직접적인 변화다. 다만 캐시 보존 기간과 조직의 데이터 보존·무기록(ZDR) 정책이 맞는지 먼저 확인해야 한다.

3. Vercel 운영 지표: ‘판단 모델’이 전체 요청의 26%

연구 데모가 아닌 제품 트래픽에서 보이는 신호

Vercel은 월 100조 토큰 이상을 라우팅하는 AI Gateway의 익명·집계 트래픽을 바탕으로 한 11월 Production Index를 공개했다. 10월 데이터에서 판단 모델은 불과 6주 만에 전체 요청의 26%를 차지했다.

지표Vercel 관측치의미
판단 모델 요청 비중26%생성 외의 분류·점수화·선택 작업이 빠르게 증가
판단 모델 지출 비중0.53%짧은 출력과 낮은 단가로 대량 호출에 적합
유료 팀의 도입약 3분의 1도입이 대규모 팀에만 머물지 않음
월 100억 토큰 이상 팀10곳 중 7곳고처리량 서비스에서 특히 강한 수요

같은 보고서에서 언어 모델 요청의 절반 이상은 출시 60일 이내 모델에 갔고, Vercel은 모델의 실사용 ‘반감기’를 약 6주로 표현했다. 이는 한 플랫폼의 관측치이며, 지출은 정가를 기반으로 한 추정치이므로 전체 시장 점유율로 일반화하면 안 된다. 그럼에도 최신 모델 교체 속도와 판단 전용 계층의 부상은 제품 설계자가 주시할 만한 신호다.

실무 체크리스트

  • 생성 모델 호출 전에 분류·라우팅 단계가 필요한지 점검한다. 실패 비용이 낮고 선택지가 제한된 작업부터 시험한다.
  • 판단 결과의 신뢰도 임계값과 사람 검토 경로를 함께 설계한다. 확률 점수만으로 고위험 결정을 자동 확정하지 않는다.
  • 에이전트 코딩 도입 시 역할 권한, 비밀정보 접근, 캐시 보존 정책을 모델 성능 평가와 같은 우선순위로 검토한다.
