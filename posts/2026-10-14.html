1. Gemini 4 Argon, 장기 작업과 개발 도구에 투입

Google은 10월 13일 Gemini 4 Argon의 Gemini 앱 제공을 발표했고, 별도 개발자 공지에서 소프트웨어 엔지니어링·기업 지식 업무·사이버 방어용 모델로 소개했다. Gemini 앱에서는 Google AI Pro·Ultra 구독자가 접근할 수 있고, 개발자는 유료 API 등급과 Google AI Ultra를 통해 AI Studio 및 Antigravity에서 시험할 수 있다. 같은 이름의 모델이라도 앱과 API의 이용 조건은 같지 않다.

1백만 토큰은 전환 작업을 대신하지 않는다

Gemini API 문서에 따르면 모델 ID는 gemini-4-argon이고 통합 컨텍스트 창과 장문 출력은 최대 1백만 토큰이다. 11월 30일까지의 도입 가격은 입력 100만 토큰당 2달러, 출력 10달러이며 12월 1일부터는 각각 4달러와 20달러로 바뀔 예정이다.

  • 캐싱: 명시적 캐싱은 지원하지 않는다. 4,096토큰 이상 프롬프트에는 암시적 캐싱이 자동 적용되며 할인율은 95%다.
  • 호출 인수: temperature, top_p, top_k는 무시된다. 기존 품질 조절값에 의존했다면 결과 비교가 필요하다.
  • 장문 작업: 출력이 64k를 넘으면 background 모드와 65,536 초과 max output을 설정하고, 어려운 프롬프트의 클라이언트 제한 시간은 15분으로 잡도록 권장한다.

따라서 단순히 모델 이름만 교체할 일이 아니다. 캐시 API 호출을 제거하고, 장문 응답의 완료 방식과 시간 초과를 고친 뒤, 실제 업무 프롬프트에서 품질·대기 시간·토큰 비용을 함께 비교하는 편이 안전하다.

2. Anthropic, 모델 증류를 겨냥한 방어 강화

Anthropic은 10월 12일 모델 증류 공격 방어 연구를 공개했다. 회사는 수많은 가짜 계정으로 모델의 추론·응답을 대량 수집해 능력을 복제하려는 행위를 증류 공격으로 정의한다. 새 방어책이 공격자가 수집한 데이터를 약 90~99% 줄였다고 밝혔지만, 이는 Anthropic의 자체 추정치다.

사전 제한·탐지·제재를 함께 적용

  • 추론 이동 제한: Claude의 보호된 추론 블록을 대화·모델·계정 사이로 옮기지 못하게 한다. Claude Fable 5.1과 Opus 5.5에서는 8월 31일 이후 생성된 새 API 계정이 이전 대화 맥락을 수정하는 것을 막는 보존 추론 기능을 적용했다.
  • 계정 대응: 의심 계정에는 더 엄격한 사용 한도를 적용하고 반복 위반 계정은 차단한다. 회사는 수만 개 계정을 차단했으며 일부는 두 시간 안에 탐지했다고 설명한다.
  • 분류기 운영: 최신 범용 모델에 분류기를 적용해 9월 이후 추출량이 10~100배 낮아졌다고 발표했다. 9월 24일부터는 증류 등 낮은 오탐률 영역에서 응답 전 차단된 요청도 과금한다.

Anthropic은 이 방어로 상당한 매출과 유료 트래픽을 포기했고, 정상 통합에도 변경이 필요했다고 적었다. API 사용자는 차단 오류율과 사용량 제한, 이의 제기 경로를 관찰해야 한다. 오탐률이 낮다는 설명이 있어도 고객별 영향은 별도로 측정해야 한다.

오늘의 관전 포인트: 긴 컨텍스트와 장문 출력은 에이전트의 범위를 넓힌다. 그만큼 제공자는 비용·대기 시간·남용을 통제해야 하고, 사용자는 모델 교체와 보안 차단이 자신의 서비스 흐름을 어떻게 바꾸는지 검증해야 한다.

출처 및 선정 기준
