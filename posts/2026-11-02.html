AI 브리핑 — 2026년 11월 02일

11월 2일 브리핑의 공통점은 에이전트가 실제 비용과 통제의 문제로 들어간다는 것이다. Google은 화면을 조작하는 Gemini Computer Use를 정식 기능으로 전환했고, OpenAI는 ChatGPT와 Codex의 사용량을 하나의 토큰 풀로 묶을 계획을 알렸다. DeepSeek은 에이전트가 쓰는 검색·가져오기 호출의 유료 전환 시점을 명확히 했다.

오늘의 핵심

  • Google의 Computer Use 도구가 Gemini Enterprise Agent Platform에서 일반 공급(GA)으로 전환됐다. 사람 확인과 조직 차원의 안전 정책이 핵심이다.
  • OpenAI는 12월부터 Plus·Pro·Business의 ChatGPT와 Codex 사용량을 토큰 기준의 공유 한도로 운영한다고 밝혔다.
  • DeepSeek은 V4.1-Flash-1017과 함께 Search·Fetch 도구를 공개하고, 에이전트 경유 호출의 과금 시작 시점을 공지했다.

1. Gemini Computer Use, 프리뷰를 넘어 정식 API 기능으로

자동 클릭이 아니라, 정책을 지키는 실행 루프

Google Cloud의 Gemini Enterprise Agent Platform 릴리스 노트에 따르면 Computer Use 도구가 일반 공급(GA)으로 전환됐다. 이 도구는 모델이 UI 작업을 제안하고, 개발자가 만든 실행 환경이 실제 행동을 수행하는 구조다. 즉 모델에 브라우저·데스크톱을 통째로 넘기는 기능이 아니라, 애플리케이션이 매 단계의 실행을 통제해야 하는 에이전트 인터페이스다.

  • 이번 GA에는 Human-in-the-Loop 안전 거버넌스가 포함됐다. 결제, 데이터 수정처럼 민감한 작업은 확인 정책을 선택적으로 구성하거나 재정의할 수 있다.
  • 관리자는 configurableComputerUseToolSafetyPolicies 제약으로 조직 전체에 지켜야 할 가드레일을 강제할 수 있다.
  • GA는 기능의 배포 상태를 뜻할 뿐, 모든 화면·모든 작업에서 무오류 자동화를 보장하지는 않는다.
Computer Use의 정식 출시는 모델이 사람을 대신해 클릭한다는 선언보다, 그 클릭을 누가 승인하고 되돌릴 수 있는지까지 API 계약에 넣었다는 변화에 가깝다.

실무에서는 실행 계정의 최소 권한, 확인이 필요한 행동의 목록, 화면·행동 로그, 재현 가능한 테스트 샌드박스를 함께 설계해야 한다. 특히 결제·삭제·권한 변경은 모델 판단만으로 자동 실행하지 않는 것이 기본이다.

2. ChatGPT와 Codex: 12월부터 "공유 토큰 한도"로

사용량을 기능별 메시지 수가 아닌 작업 복잡도로 계산

OpenAI의 사용량 한도 안내에 따르면 12월부터 Plus·Pro·Business 플랜의 ChatGPT와 Codex 사용량은 하나의 공유 한도로 운영된다. 사용량은 메시지 수가 아니라 모델이 처리·생성하는 정보 단위인 토큰으로 측정하며, 고급 모델과 복잡한 작업일수록 더 많은 한도를 쓴다.

  • 일반적인 Instant chat은 이 공유 한도에서 차감되지 않는다.
  • 사용자는 설정의 Usage 화면에서 합산 잔여량과 초기화 시점을 확인할 수 있게 된다.
  • 한도에 도달하면 초기화를 기다리거나 플랜을 올리고, 지원되는 기능에서는 크레딧을 구매해 계속 사용할 수 있다.

이는 단순한 과금 화면 변경이 아니다. 조사·코딩·도구 사용을 넘나드는 에이전트 작업이 ChatGPT의 주된 경험으로 합쳐지면서, 팀은 어떤 일을 Chat에서 가볍게 처리하고 어떤 일을 Codex에 오래 맡길지 토큰 예산 관점으로 운영하게 된다.

3. DeepSeek V4.1-Flash-1017: 검색 호출도 에이전트 비용이 된다

공개 모델 업데이트와 Search·Fetch 유료 전환

DeepSeek은 V4.1-Flash-1017 업데이트를 웹·앱·API에 제공하고, 자사 검색 엔진 기반 Search·Fetch API를 공개했다. 회사는 새 모델이 자기 피드백을 활용해 완성형 프로젝트 개발을 개선하고, 이전판보다 더 짧은 출력과 빠른 작업 완료를 목표로 한다고 설명한다.

  • Search와 Fetch는 각각 1,000회당 0.75달러다.
  • DeepSeek Harness, Claude Code, Codex의 서버 측 도구를 거친 Search·Fetch 호출도 10월 31일 16:00 UTC부터 과금이 시작됐다.
  • 모델 가중치는 Hugging Face와 ModelScope에서 공개돼, 도입팀은 API 사용과 자체 호스팅을 비교할 수 있다.
에이전트의 비용은 이제 "모델 토큰"만이 아니다. 검색, 브라우징, 실행, 재시도 같은 도구 호출이 누적되므로 작업 단위의 총비용을 추적해야 한다.

개발팀은 검색 호출에 캐시·중복 제거·작업별 예산 상한을 두는 편이 안전하다. 특히 기존에 무료였던 도구 호출을 전제로 만든 자동화는 호출량과 요금 발생 시점을 다시 점검할 필요가 있다.
