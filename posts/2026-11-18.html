오늘의 중심은 에이전트 성능의 상향과 그에 맞춘 권한·안전·감사 구조입니다. OpenAI는 더 강한 GPT-6.2 계열을 내놓으며 사이버·자기개선 능력의 새 안전 등급을 공개했고, Google은 Gemini Tasks를 한국을 포함한 6개국에서 무료로 풀었습니다. Microsoft는 에이전트가 실제 업무를 수행하는 환경을 겨냥해 투명성 표준과 관찰성을 전면에 내세웠습니다.

1. OpenAI, GPT-6.2 Astra·Sol 공개

전문 작업용 Astra와 일상 에이전트용 Sol

OpenAI가 GPT-6.2 Astra와 GPT-6.2 Sol을 공개했습니다. Astra는 복잡한 코딩·전문 업무·과학 작업에, Sol은 텍스트·이미지·도구를 결합하는 일상적 코딩과 에이전트 워크플로에 맞춘 모델입니다. 두 모델은 ChatGPT Work·Codex의 Plus, Pro, Enterprise, Edu 사용자와 API에서 제공됩니다.

  • Astra API 가격은 이전 GPT-6 Astra보다 입·출력 토큰 기준 20% 낮아졌고, 캐시 입력 할인은 60%입니다.
  • Sol은 GPT-6.1 Sol의 API 가격을 유지하면서 다단계 에이전트 작업의 효율 개선을 목표로 합니다.
  • OpenAI는 GPT-6.2 Astra가 외부 공개 모델 가운데 처음으로 자사 AI 자기개선 ‘High’ 기준을 충족했다고 평가했습니다.

성능 수치는 OpenAI 및 관련 평가의 결과이므로 실제 도입 전에는 자체 업무·비용·오류율로 검증해야 합니다. 특히 두 모델은 OpenAI의 준비도 프레임워크에서 사이버 보안은 Critical, 생물·화학은 High로 분류됐습니다. 이에 따라 고위험 사이버 지원의 기본 제한과 모니터링을 강화해 출시했습니다.

핵심은 성능만이 아닙니다. 모델이 더 긴 작업을 계획하고 실행할수록, 어떤 작업을 허용하고 언제 중단할지를 제품 기본값으로 설계해야 한다는 신호입니다.

2. Gemini Tasks, 한국 포함 6개국에 무료 배포

일정·장보기·청구서 정리에서 전화·구매 전 단계까지

Google은 Gemini Tasks를 미국·일본·한국·캐나다·호주·인도에서 수억 명에게 무료로 순차 배포한다고 발표했습니다. Gemini 4 Hydrogen을 기반으로, 앱을 Task 모드로 전환하거나 문자·이메일로 일을 넘기면 일정 예약, 장보기 목록, 청구서 분석과 같은 일을 처리하도록 설계됐습니다.

예를 들어 Google 앱의 기존 맥락을 바탕으로 가까운 업체에 전화를 걸고, 가능한 시간을 캘린더에 넣는 흐름을 제시합니다. Google은 상대방에게 AI임을 알리며, 구매 버튼을 누르는 등의 중요 단계 전에는 확인 또는 사전 승인을 받도록 설계했다고 설명합니다.

  • 작업은 계정 전용의 하드웨어 격리 가상 머신에서 실행되며, 다른 사용자와 공유하지 않는다고 Google은 설명합니다.
  • 검색 결과·웹페이지용 프롬프트 인젝션 필터와 Safe Browsing을 방어 계층으로 사용합니다.
  • 사용자는 작업 설정을 바꾸고, 연결한 Google·서드파티 앱을 해제하거나 대화 기록을 삭제할 수 있습니다.

무료 전환은 접근성을 크게 넓히지만, 메일·캘린더·결제수단처럼 민감한 맥락을 연결하는 기능입니다. 초기에는 자동 실행 범위를 작게 두고, ‘항상 허용’ 같은 반복 승인 설정은 신뢰할 수 있는 저위험 작업에만 적용하는 편이 좋습니다.

3. Microsoft, AI Transparency Initiative 출범

‘결과는 보이지만 과정은 보이지 않는다’는 기업 에이전트의 문제

Microsoft는 Ignite에서 Accenture, Adobe, KPMG, Mastercard, Volvo Cars 등을 포함한 40개 이상 조직과 AI Transparency Initiative를 시작했습니다. 목적은 모델·공급자에 관계없이 AI의 보안·거버넌스·투명성을 위한 공통의 개방형 접근을 만드는 것입니다.

Microsoft는 기업이 에이전트에 데이터·도구·자격증명을 연결하면서, 요청과 결과 사이에 실제로 무슨 일이 있었는지 독립적으로 재구성하기 어려운 ‘증거 공백’이 생긴다고 짚었습니다. 이 이니셔티브는 NIST의 SI Agent Standards Initiative 참여 확대, 다수 조직과의 개방형 표준 개발, 제품 전반의 데이터 상호작용 가시성 강화를 축으로 합니다.

같은 행사에서 Microsoft는 작업 라우팅·분류·검증용 Microsoft-Decision-1.1의 일반 공급과 코드·사이버·이미지·오디오용 새 모델군, 보안용 Microsoft Perception의 일반 공급도 발표했습니다. 에이전트의 ‘생성 능력’ 못지않게 비용·권한·행동 기록을 운영 단위로 관찰하는 시장이 커지고 있습니다.

정리: 오늘의 발표는 AI가 답변하는 도구에서 실제 작업을 수행하는 시스템으로 넘어가는 속도를 보여줍니다. 사용자는 Gemini의 연결 권한을, 개발팀은 GPT-6.2의 고위험 사용 경로를, 기업은 에이전트의 행동을 재현·감사할 체계를 먼저 점검해야 합니다.
