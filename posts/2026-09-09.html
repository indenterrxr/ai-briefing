1. 나비에–스토크스 증명 제안, 성과와 공로 논쟁이 동시에

9월 8일 발표. OpenAI는 GPT-6 Astra보다 강력한 내부 모델이 나비에–스토크스 밀레니엄 문제의 해법을 만들었다고 주장했다. 매끄러운 외력이 작용하는 조건에서 유체가 유한 시간 안에 특이점을 형성한다는 분석적 증명과 Lean 형식화를 공개했다. 공식 발표

회사 설명에 따르면 해당 결과를 낸 그룹은 약 1만 개 동시 에이전트를 사용했고, 해법 도출까지 약 88시간, 이후 Astra를 이용한 Lean 형식화·검증에 17시간이 추가됐다. 일반 ChatGPT 이용자가 같은 작업을 재현할 수 있다는 의미는 아니다.

현재는 OpenAI가 공개한 증명 제안이다. 회사가 보고한 형식 검증을 독립적인 학계 검토 완료나 밀레니엄상 수상 확정과 동일하게 취급하지 않는다.

함께 봐야 할 논란: Axios는 외부 수학자들의 미공개 연구와 공로 배분 문제가 불거졌다고 보도했다. OpenAI는 문제 해결을 위해 특정 사용자 데이터를 열람하지 않았다고 밝혔지만, 비식별 사용 데이터가 모델 개선에 간접적으로 기여했을 가능성은 완전히 배제하지 않았다. 데이터 도용이 입증됐다는 뜻은 아니다. Axios 보도

반응: 관련 r/technology 토론은 검색 시점 901점으로 표시됐다. 댓글에서는 연구자의 신뢰와 공로 문제가 집중적으로 논의됐다. 이는 변동하는 검색 스냅샷 점수이며 전체 커뮤니티 순위나 주장에 대한 검증은 아니다. 토론

2. ChatGPT Images 2.5: 그리기와 수정의 진입점을 늘렸다

9월 8일 공식 릴리스 노트. OpenAI는 이미지 세부 표현, 편집 정확도, 생성 속도를 개선했다고 밝혔다. 새 흐름은 다음과 같다. 공식 변경 기록

  • 템플릿: Images → Templates에서 시작해 내용을 조정한다.
  • 모바일 스케치: 입력창의 @ 메뉴에서 Sketch를 골라 직접 그린 뒤 원하는 결과를 설명한다.
  • 편집 댓글: 모바일에서 생성 이미지를 전체 화면으로 열어 수정하거나 변경 지시를 남긴다.
  • 프롬프트 공유: 다른 사람이 자신의 버전을 만들 수 있도록 생성 지시를 공유한다.

기존 이미지 생성 한도는 그대로다. 템플릿은 아직 Work 모드에서 지원되지 않는다. 체감 속도 향상은 공식 설명이며, 이번 브리핑에서 별도의 속도 비교를 수행한 것은 아니다.

3. Claude: 무조건 오래 생각시키기보다 비용·성능을 측정한다

9월 8일 공개. Anthropic은 Claude Platform의 비용 절감 가이드와 Claude Code에서 사용하는 세 가지 도구를 소개했다. 공식 가이드

  • /claude-api prompt-audit: 프롬프트·스킬·도구 설명에서 불필요한 절차나 상충하는 지시를 점검한다.
  • /claude-api cost-optimize: 토큰 소비를 분석하고 캐싱, 요청 축소, 출력 제한, 배치 처리 등 절감 방법을 적용한다.
  • /claude-api hillclimb: 평가 데이터를 학습용·검증용으로 나누고 모델, 추론 노력, 프롬프트 구성을 반복 조정한다.

회사의 CursorBench 3.2 예에서는 Fable 5.1의 낮은 추론 노력이 Fable 5의 높은 추론 노력과 비슷한 성능을 약 3분의 1 비용으로 냈다. 이는 특정 평가와 가격 조건의 결과다. 실제 서비스에서도 같은 절감률이 보장되는 것은 아니므로, 독립된 검증 데이터에서 품질과 비용을 함께 확인하는 것이 핵심이다.

4. Google Pics: 5월 예고에서 9월 Workspace 정식 배포로

9월 1일 발표한 배포 소식. 기존 브리핑의 5월 제품 소개 이후 변화는 실제 도입 일정이다. Pics는 이미지 속 개별 객체와 텍스트를 편집하고, Docs·Slides 안에서 이미지를 수정하며 공동 작업을 지원한다. Google 공식 배포 공지

Drive에 저장된 거의 모든 이미지를 한 번에 열어 편집하는 확대 기능은 향후 수 주 내 제공 예정으로 안내됐다. 오늘 모든 계정에서 이용 가능하다고 단정할 수 없다. 생성형 기능의 확대 이용량은 적어도 2027년 2월 28일까지 제공되며 이후 달라질 수 있다.

오늘의 관전 포인트

연구 영역에서는 증명의 검토와 공로 배분, 제품 영역에서는 이미지 편집의 접근성과 에이전트 비용 관리가 핵심이다. 새 모델 발표 자체보다 검증 상태·실제 배포 범위·작업당 비용을 확인할 때 변화의 의미가 분명해진다.
