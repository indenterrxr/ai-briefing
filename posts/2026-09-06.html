1. Claude, 페르마 정리를 컴퓨터가 검증할 수 있는 증명으로

발표일: 9월 4일. Anthropic은 Claude가 11일 동안 대체로 자율적으로 작업해 페르마의 마지막 정리의 완전한 Lean 형식화를 만들었다고 밝혔다. 회사 발표 수치는 약 1,300만 줄의 코드와 2만 9,500개의 중간 정리다. 이는 이미 알려진 수학적 증명을 컴퓨터가 단계별로 검사할 수 있도록 옮긴 성과다. Anthropic 연구 발표

관련 형식화 프로젝트를 이끄는 수학자 Kevin Buzzard는 직접 코드를 컴파일하고 comparator 검사를 실행해 통과를 확인했다고 썼다. 그는 자동 형식화의 진전을 높이 평가하면서도, 사람이 탐색할 수 있는 설명과 재사용 가능한 수학 라이브러리를 만드는 자신의 작업은 계속된다고 설명했다. Buzzard의 직접 검토

관심도: Reddit r/singularity 관련 게시물은 검색 수집 시점에 597표를 기록했다. 점수는 변동하며 연구의 정확성을 판정하는 지표는 아니다. 커뮤니티 토론

편집 해석: 이번 성과의 핵심은 방대한 기존 논증을 기계 검증 가능한 형태로 바꾸는 속도다. 공개된 증명과 검증 절차를 함께 보는 것이 발표의 의미를 이해하는 데 도움이 된다.

2. Codex, 보관형 리셋으로 원하는 때 사용량 창 초기화

9월 3·4일 지급 조건을 담은 공식 도움말 확인. OpenAI는 자격을 갖춘 기존 Plus·Pro·Business 사용자에게 양일 각각 보관형 리셋을 지급한다고 안내했다. 새 계정에는 생성 시각 조건이 있고, 플랜·지역·계정 상태에 따라 대상 여부와 반영 시점이 달라진다. OpenAI 공식 안내

보관형 리셋은 계정에 저장되는 일회성 사용량 초기화 혜택이다. 사용하면 Codex의 5시간·주간 사용량 창이 초기화되고 주간 리셋 날짜도 바뀐다. 영구 한도 증가나 API 크레딧으로 해석해서는 안 된다.

  • 앱·CLI·웹의 Settings → Usage에서 사용 가능한 리셋과 만료일을 확인한다.
  • 사용자가 적용해야 하며, 적격 사용량 창이 하나 이상 실제로 초기화될 때 소모된다.
  • 사용하지 않은 리셋도 만료될 수 있으므로 계정에 표시된 조건을 확인한다.

3. GitSpawn: 코딩 에이전트가 작업을 읽는 순간의 취약점

연구 원문 날짜: 9월 1일, 이번 브리핑 첫 소개. Manifold Security는 Claude Code·Codex·Cursor 등을 포함한 7개 에이전트에서 8개 취약점을 보고했다. 프로젝트 상태를 읽기 위해 내부적으로 실행하는 Git 명령이 저장소의 실행 가능 설정을 그대로 받아들이면, 일부 경로에서는 신뢰 확인이나 도구 승인 전에 코드가 실행될 수 있다는 내용이다. Manifold 원문

공격 조건은 .git 폴더까지 포함한 프로젝트가 ZIP·공유 폴더 등의 형태로 전달되는 경우다. 연구진은 일반적인 git clone·fetch·pull이 해당 로컬 설정을 옮기지는 않는다고 구분했다.

연구진의 9월 1일 확인 기준으로 Codex·Cursor 등은 수정됐고, Qwen Code·Grok Build·Hermes 및 Claude Code의 별도 리뷰 경로 등 4건은 미수정 상태였다. 이는 연구 시점의 상태이며 이후 모든 버전의 상태를 뜻하지 않는다. 개발팀은 제품별 수정 공지와 외부 프로젝트 전달 방식을 함께 확인할 필요가 있다.

4. Gemini, MrBeast와 다년 협업으로 대중 접점 확대

발표일: 9월 2일. Google은 Beast Industries와의 협업을 YouTube에서 Gemini와 Google Health까지 확대하는 다년 파트너십을 발표했다. 공식 안내는 9월 5일 예정 영상에서 정글·사막·북극 환경의 도전에 Gemini를 활용하고, 향후 캠페인에서 대규모 촬영 기획과 진행에 앱을 사용하는 모습을 보여 준다고 설명한다. Google 공식 발표

이번 소식은 신규 모델이나 모든 사용자에게 배포된 새 기능 발표가 아니라, 활용 사례를 대규모 시청자에게 알리는 협업이다. 편집 해석: AI 경쟁에서 실제 사용 장면을 보여 주는 크리에이터 유통 채널의 비중이 커지고 있다. 영상 속 연출을 제품의 독립 성능 검증으로 받아들이기는 어렵다.
